The 3 rules

  2. 2Cite the file and line for every fact. Do every calculation in code, with units.
  3. 3Missing document: NOT FOUND, and name the document that would prove it. Expired, an estimate or in conflict: NEEDS CHECK, with the reason in one sentence.This is a short version. Copy the full rules word for word from project-instructions.md in the kit.

What the status means

  • OKProven by a file. A file can also prove a problem, so add an action when it does.
  • NEEDS CHECKThe file exists, but it is expired, an estimate or in conflict with another file.
  • NOT FOUNDNo file. Name the document that would prove it.
  • PARTIALOnly in the Passport: some data points are proven, others are missing.

If a question has several parts, the weakest part sets the status.

Green claims: drop “climate neutral” based on offsets, and vague words like “eco-friendly”. Germany has banned them since 27 Sept 2026. In Poland the ban starts on 27 Sept 2027, but misleading claims are already illegal there. Everywhere, a safe claim is specific and measured, true for the product it sits on, and backed by one file. GREEN = proven by a file · AMBER = maybe true, no proof · RED = files say no, or banned.
