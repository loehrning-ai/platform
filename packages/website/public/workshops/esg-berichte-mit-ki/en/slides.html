Learning objective

Every answer that leaves the company carries its evidence: a file and line that covers the period, scope and finality of the answer, or the name of the document that is missing.

After this hour you can

  1. 1Hold an answer against its file with four checks: quote, period, scope, final.
  2. 2Give every answer one of three statuses and name the missing document.
  3. 3Have Claude run the same check on your own files, with the skill and the project instructions.

The tool · evidence-check.md

The evidence check

Put the answer next to its file. Check four things:

  1. l. 6
    QUOTE

    Which file, which line says it? No quote, no COVERED.

  2. PERIOD

    Does the file cover the whole period of the answer, and is it valid on the reference date? Count months, not rows.

  3. SCOPE

    Does the file cover everything the answer talks about? 12 of 40 ha are not "our vineyards".

  4. DRAFT
    FINAL

    Is the file final: measured, signed, audited? A draft, an offer and an estimate are not.

  • COVERED

    All four hold. Bad news can be covered too; then an action follows.

    Water 2025: 4,630 m³ from 12 of 12 invoices
  • WEAK

    The file is there, but expired, estimated, a draft, unsigned or contradicted.

    Solar yield 180 MWh: an estimate in an unsigned offer
  • GAP

    No file says it. Write which document would prove it.

    Electricity 2025: September missing, request invoice EL-25-09

Several parts: the weakest part counts.

Claims to consumers go against the ban list first

  • 4a"eco-friendly", "green" without recognised excellent environmental performance
  • 4ba claim about the whole that is true only for a part
  • 4c"climate neutral" based on offsetting
  • 2aan own label without a certification scheme or public authority

Directive (EU) 2024/825, Annex I. Banned since 27.09.2026, with or without evidence.

Setup · once, 10 minutes

Create the project

  1. Unzip the kit.
  2. Create a new project "Crvena Zemja Evidence".
  3. Paste the whole text of project-instructions.md as project instructions and save.
  4. Add the 13 files from files/ to the project. Not the requests: they ask, they prove nothing.
  5. Steps 1 to 4 each start a new chat in the project. Step 5 runs in the chat of step 4.

Turn on code execution:In “Settings”, “Capabilities”, turn on “Code execution and file creation” (“Create and edit files” in the new layout).

Before real company data: check the privacy settings and clarify whether company files may go into Claude.

Appendix 1 · Sources

Sources

  • Directive (EU) 2024/825amends Directive 2005/29/EC. Annex I points 2a, 4a, 4b, 4c, 10a: always banned. Art. 6(2)(d): claims about future environmental performance only with a verifiable plan. Applies since 27.09.2026, in Germany through the UWG.
  • BGH, judgment of 27.06.2024, I ZR 98/23Whoever advertises with "climate neutral" explains in the advertisement itself whether reduction or offsetting is meant.
  • Delegated Regulation (EU) 2026/1560VSME, the EU's voluntary sustainability standard for SMEs, since 24.09.2026. Basic Module B1 to B11.
  • Directive (EU) 2026/470Value-chain cap, financial years from 1.1.2027 (appendix 2).

Summarised in files/green_claims_rules.md and files/vsme_basic_module.md. A learning aid, not legal advice.
