Appendix · only if asked

If asked

Memory

Free, Pro, Max: on by default. Team, Enterprise: an owner makes it available, then each member turns it on. Owners cannot read members' memories.

Connectors

Claude uses your own permissions in the connected service. Owners choose which are on.

Incognito

Ghost icon. Not saved to history or memory. Personal plans: also not used to improve Claude. Team, Enterprise: still in exports, org retention applies.
