The folder checklist

Tick what you can find in 10 minutes. Circle the 3 you will collect first.

Personal data: IDs only, no names. Never upload real patient or employee files. Before you upload company files, switch off model training in Settings > Privacy, and ask your manager first.

The 3 rules

  1. 1Only our files. Never invent a fact, a date or a number.
  2. 2Cite the file and the row (or the quoted words) for every fact. Never cite line numbers. Do every count and date calculation in code.
  3. 3Give every answer a status (below) and name the document that would close each gap.The full wording is rule 3 in project-instructions.md in the kit.

What the status means

  • COVEREDA current file answers the request in full, even when the answer is bad news; then add an action.
  • WEAKA file answers, but it is old, has an empty or “not recorded” cell, or disagrees with another file; say which.
  • GAPNo file answers it, or the file only says “pending”, “none” or “not done”; name the document that would close it.

Several parts: the part that is missing or old sets the status; name it. A named owner or approver counts as signed.

Before every upload, ask three things. Data: what is in the file? Place: which country, who runs the machine, what do the logs keep, who can log in? Paper: which contract and which company rule allow it? Open weights is not a location: write down the model, version, licence, host, country, logs and access of every AI tool. Claims: GREEN = a file proves every word · AMBER = not fully proven · RED = the files say no.
