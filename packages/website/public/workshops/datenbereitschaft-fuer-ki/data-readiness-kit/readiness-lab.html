Fix the AI's data.

Help a made-up subscription company, FOLDLINE, get a trustworthy monthly revenue answer. The defaults are deliberately weak. The first tidy answer has a twist.

This is a fixed browser simulation. It calls no AI and connects to no database. MRR means monthly recurring revenue: 10 subscriptions at €20 per month give €200 MRR. “Ending” means the balance at month end.

The simulation only knows this one FOLDLINE question, so it grades only this question. To practise wording your own question, use the notes below; they are never graded.

      The ten checks behind the verdict

      Optional detail: five gates, two checks each. A test run sets each level. “Proven” unlocks only when a matching test passes, and a document can never outrank a failed test. You may mark “Documented” only for checks your test set did not run.

      0 · Unproven
      No evidence, or the test failed.
      1 · Documented
      A written claim. No test has shown it works.
      2 · Proven
      A repeatable test passed.

        What this lab does not prove

        • It is a fixed simulation. A pass says nothing about your own systems or your employer's data.
        • A correct value does not show that the answer used the definition. In the course's recorded runs the answers cited it 0 of 3 times.
        • Instructions guide, grants enforce: only a database permission makes a forbidden read fail.
