# Wochencheck als geplante Aufgabe (bezahlte Tarife)

Eine geplante Aufgabe läuft nur in einem bezahlten Claude-Tarif von selbst (Pro, Max, Ultra, Team, Enterprise). Der eingebaute Zeitplan bietet stündlich, täglich, wöchentlich oder werktags. Monatlich gibt es nicht, also wird das Register jede Woche geprüft.

Einmal einrichten, in Claude Cowork: links in der Seitenleiste auf „Scheduled“ klicken, dann „New task“ und „Set up manually“. Wöchentlich und einen festen Tag wählen, der Aufgabe register.csv und check.py aus Schritt 4 geben und diesen Prompt einfügen. Jeder Lauf ist eine eigene Cowork-Sitzung.

    Lies register.csv. Führe check.py mit dem heutigen Datum aus. Gib drei Listen aus: abgelaufen, läuft in den nächsten 60 Tagen ab, fehlt. Entwirf dann eine kurze Nachricht pro Rolle der Verantwortlichen. Nur Entwürfe: nichts senden und keine Zeile ändern.

Jede Woche liest eine benannte Person die Listen und schickt die Nachrichten. Eine Lücke schließt ein neues, datiertes Papier, nie eine geänderte alte Zeile. Geplante Aufgaben laufen entfernt, mit den Dateien in deinem Claude-Konto. Eine Aufgabe, die Dateien auf dem eigenen Rechner braucht, läuft nur, solange dieser Rechner an ist.
