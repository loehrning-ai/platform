# Übertragungsblatt: dein eigenes Audit auf einer Seite

Nimm zuerst ein erfundenes Beispiel. Echte Zeilen mit Kennungen statt Namen sind personenbezogene Daten, solange du den Schlüssel hast.

| Feld | Dein Audit | Beispiel: Gradba-Pro (erfunden) |
|---|---|---|
| 1. Wer prüft | | das Arbeitsinspektorat (DIT) |
| 2. Welches Gesetz | | ZIN, ZRO, ZBZR, Gesetz über die Evidenzen |
| 3. Welche Papiere | | Verträge, Anwesenheitslisten, Überstundenmeldungen, Lohnzeilen, Urlaubsbescheide, Sicherheitserklärung |
| 4. Wer hat jedes | | Büroleiterin, externe Buchhaltung, der Ordner |
| 5. Welche Frist | | Mitteilung Mo 23. Nov, Besuch 27. Nov um 09:00 Uhr, Papiere 3 Kalendertage nach dem schriftlichen Verlangen |
| 6. Dein Satz | | Vor dem 27. November 2026 prüft die Büroleiterin die Anwesenheitslisten gegen ZRO Art. 116(8). |

Satzvorlage: Vor [Datum] prüft [Rolle] [Papier] gegen [Regel].

Datenleiter: Stufe 1 öffentlicher Text. Stufe 2 nur erfundene Zeilen. Stufe 3 die KI schreibt die Prüfung und du führst sie auf deinem eigenen Rechner aus. Stufe 4 echte Daten im Werkzeug nur mit allen vier Toren: ein Geschäftsabo, ein Auftragsverarbeitungsvertrag, Sicherheitsmaßnahmen, Regeln für die Übermittlung ins Ausland.
