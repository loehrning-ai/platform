# Transfer sheet: your own audit on one page

Use an invented example first. Real rows with ids instead of names are still personal data while you hold the key.

| Box | Your audit | Example: Gradba-Pro (invented) |
|---|---|---|
| 1. Who checks | | the labour inspectorate (DIT) |
| 2. Which law | | ZIN, ZRO, ZBZR, Law on Records |
| 3. Which papers | | contracts, attendance sheets, overtime notices, pay lines, leave decisions, safety statement |
| 4. Who holds each | | office manager, outside accountant, the binder |

| 6. Your sentence | | Before 27 November 2026, the office manager checks the attendance sheets against ZRO Art. 116(8). |

Sentence template: Before [date], [role] checks [paper] against [rule].

Data ladder: level 1 public text. Level 2 invented rows only. Level 3 the AI writes the check and you run it on your own machine. Level 4 real data in the tool only with all four gates: a business subscription, a data processing contract, security measures, rules for sending data abroad.
