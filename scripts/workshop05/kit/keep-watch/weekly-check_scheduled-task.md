# Weekly check as a scheduled task (paid plans)

A scheduled task runs on its own only on a paid Claude plan (Pro, Max, Ultra, Team, Enterprise). The built-in schedule offers hourly, daily, weekly or weekdays. It has no monthly option, so the register is checked every week.

Set it up once in Claude Cowork: click "Scheduled" in the left sidebar, then "New task" and "Set up manually". Choose weekly and one fixed day, give the task register.csv and check.py from Step 4, and paste this prompt. Each run is its own Cowork session.

    Read register.csv. Run check.py with today's date. Print three lists: expired, expiring in the next 60 days, missing. Then draft one short message per owner role. Draft only: send nothing and change no row.

Every week one named person reads the lists and sends the messages. A gap is closed with a new dated paper, never by changing an old row. Scheduled tasks run remotely with the files saved to your Claude account. A task that needs files on your own computer runs only while that computer is on.

Free plan: use monthly-check_by-hand.md.
