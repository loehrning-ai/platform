# Monthly check of the register

Once a month, on a fixed day, one named person does this. The register is a working file and never replaces a paper.

Use the script check.py from Step 4 and this prompt:

    Run check.py on register.csv with today's date. Print three lists: expired, expiring in the next 60 days, missing. Then draft one short message per owner role. Draft only: send nothing and change no row.

A named person reads the lists, sends the messages and writes a new dated paper for every gap. Never change an old row to hide a gap.

To keep this going after the workshop, see extras/keep-watch/: a weekly scheduled task on paid plans, the same check by hand on a Free plan.

## Other homes for the same register

The same register works in a spreadsheet (a formula such as a date before today marks expired rows), in a Microsoft list or in a small database such as SQLite. The columns and the three lists stay the same. Dates only, no health content.
