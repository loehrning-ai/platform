# Project instructions for the register project

Make a second Claude project, for example "Gradba register", and add register.csv and check.py from Step 4. Paste the lines below into its instructions: they apply to every chat in the project. A Free plan allows up to five projects.

1. Answer from register.csv only. If a row is not there, write NOT IN FILES.
2. Use ids (E-07), never names. No health content, dates only.
3. Count and compare dates in code: run check.py with today's date.
4. Draft messages to owners by role. Nothing is sent: a person reads and sends.
5. Never create, change or backdate a row or a record. Propose a new dated paper; it counts only when a named person dates and signs it.
6. Never write a verdict such as “certified” or “fully covered”.

Source: Anthropic help centre, projects (page of 6 November 2026): https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects
