# Fünf Schritte für jede wichtige KI-Antwort

1. **Zerlegen.** Welche einzelnen Sätze können wahr oder falsch sein?
2. **Quelle öffnen.** Nicht den nächsten Chat. Die Studie, Verordnung,
   Dokumentation oder den Quellcode.
3. **Nachrechnen.** Nenner, Zeitraum, Prozentpunkte, Rundung.
4. **Gegenfall suchen.** Unter welcher Bedingung wäre die Aussage falsch?
5. **Eskalation entscheiden.** Braucht das eine Fachperson?

Die Reihenfolge ist absichtlich.

Wer zuerst fragt "Stimmt das?", bekommt oft nur eine zweite flüssige Antwort
auf die erste.

Wer die Behauptung zerlegt, kann sie prüfen.

Zwei übereinstimmende KI-Systeme sind übrigens keine zwei unabhängigen
Quellen.

Sie können denselben Fehler aus ähnlichen Trainingsdaten reproduzieren.

Prüfung beginnt außerhalb des Modells.
