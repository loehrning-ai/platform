# Channel strategy

## Website

The website is canonical. Long-form material, citations, review dates,
corrections, structured data, and durable links live there.

One strong article is worth more than five near-duplicate posts.

## Personal LinkedIn profile

Use the named author's profile for interpretation, working notes, examples,
and discussion. Each post must stand on its own while pointing to the canonical
resource when one exists.

Post forms:

- one claim, its source, and its practical consequence;
- a native document with a checklist or diagram;
- a 30–90 second demonstration;
- a correction or change note;
- an open question that requests evidence or experience, not engagement.

## loehrning.ai LinkedIn Page

Use the Page as the institutional record:

- new canonical resources;
- meaningful updates;
- contribution and correction calls;
- reusable teaching material.

Do not duplicate the founder post verbatim.

## GitHub

GitHub owns software, issues, corrections, and contributions. Broad proposals
belong in Discussions when enabled. Concrete defects need narrowly scoped
issues with source links and acceptance criteria.

## External learning platforms

Link to KI-Campus, Elements of AI, appliedAI, openHPI, KI & Me,
Mittelstand-Digital, and other strong material when it already solves the
learning job.

Eligible open educational resources should be prepared for discovery through
OERSI or WirLernenOnline. Submission requires license and metadata review.

## Cadence

The eight-week program uses:

- one canonical website asset per week;
- two founder-profile derivatives per week;
- one institutional Page record per canonical asset;
- one biweekly LinkedIn newsletter synthesis after the source articles exist.

Cadence never overrides the evidence gate. A missed date is better than a
false claim.

## Distribution rules

- No engagement bait, reaction voting, attention tagging, or pods.
- No claims about optimal posting time or link penalties without current
  platform evidence.
- No generic AI-news summary.
- No more than three relevant hashtags.
- Reply to substantive corrections with source updates, not defensiveness.
- Keep campaign parameters free of personal data.
