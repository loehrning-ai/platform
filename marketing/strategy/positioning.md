# Positioning

## Category

loehrning.ai is a free German-language AI learning platform and an open-source
software project.

It is not:

- an AI consultancy;
- a lead-generation site;
- a certification body;
- a legal-advice service;
- a generic AI-news publication;
- a directory that tries to contain every course.

## Audience promise

You leave with a clearer mental model, a task you can perform, and a method for
checking whether the result is trustworthy.

## Differentiation

The platform occupies the layer between large course catalogs, fast-moving AI
news, and vendor marketing:

- German-first orientation with English technical depth.
- Short routes into substantial courses, books, and practical examples.
- Germany and EU context without compliance theater.
- Sources, review dates, limitations, and public corrections.
- Executable examples and open-source code.
- Explicit referrals to stronger external material instead of duplication.

This is a strategic inference from the reviewed German learning landscape. It
is not a claim that no similar project exists.

## Message hierarchy

1. **Understand:** how current AI systems work and fail.
2. **Use:** apply them to bounded, real tasks without exposing sensitive data.
3. **Verify:** test claims, calculations, sources, and failure modes.
4. **Shape:** make informed choices about work, education, law, and open tools.
5. **Contribute:** correct, translate, teach, or improve the public material.

## Product proof

Use observable proof:

- real course routes;
- browser-readable books;
- working exercises and demonstrations;
- public source and commit history;
- documented licenses;
- dated sources and corrections.

Do not use:

- invented learner counts;
- implied institutional recognition;
- employer logos as endorsements;
- unsupported superlatives;
- urgency language;
- pending features described as available.

## Voice

Write in German `du` form outside legal pages. Use short sentences, concrete
roles, named sources, and direct limitations. Prefer one verified example over
five abstract claims.

The platform does not need to sound large. It needs to be correct, useful, and
maintained.
