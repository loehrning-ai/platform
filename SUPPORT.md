# Support

After repository publication, use its issue tracker for reproducible bugs, factual errors, and focused enhancement proposals. Include the affected route, expected behavior, actual behavior, browser or runtime version, and reproduction steps.

Use `tim@loehrning.ai` for private security reports only as described in [SECURITY.md](SECURITY.md).

The learning content is maintained on a best-effort basis. It is educational material, not legal, tax, security, or compliance advice. Production integration, provider accounts, custom deployments, and individual consulting are outside community support.
